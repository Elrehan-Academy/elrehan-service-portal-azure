# Elrehan Service Portal — Notices

## Project

Elrehan Service Portal (ESP) is a customized deployment of the iTop
open-source IT service management and CMDB platform.

Powered by iTop, developed by Combodo.

Branding and automation by Elrehan.

Elrehan Service Portal is not presented as an official Combodo product
and is not endorsed by Combodo SAS.

## Elrehan modifications

Elrehan Service Portal adds deployment automation, Azure infrastructure
automation, container packaging, operational tooling, and visual/user
interface branding around the iTop platform.

The Elrehan modifications are identified in this source repository and
its Git history. Release deployment manifests record the source commit
used to create a deployment artifact.

The original iTop copyright, license, warranty and third-party notices
must not be removed from redistributed copies.

## Source availability

The preferred form of the Elrehan Service Portal source is the source
repository from which a release is produced.

Before public distribution of an ESP deployment artifact, the matching
source revision and applicable license and notice files must be made
available to recipients.
